# ZeroTrace Mobile — Official Release Notes

**Version:** 1.0.0  
**Release Date:** 2026-07-08  
**Platform:** Android

## Official Launch Announcement

ZeroTrace Mobile is now officially released as **Version 1.0.0**.

We have **formally ended the beta phase**.  
All prior beta labeling has been retired, and this build is the first official public release.

## Highlights in 1.0.0

- Official production-ready Android APK release.
- Refined startup experience:
  - Splash video playback on launch.
  - First-time introduction video flow after permission response.
- Improved visual polish:
  - Centered splash video presentation.
  - Consistent mint-accent mobile UI refresh for a cleaner, professional look.
- Stable release build pipeline with R8/proguard release compatibility fixes.
- Default theme behavior set to **System** mode.

## Privacy & Permissions

- On-device scanning and sanitization workflow.
- Media/file permissions are requested for user-selected content scanning.
- Internet access is used for optional marketplace/network features only.

## Installation

Install the official release APK:

`build/app/outputs/flutter-apk/app-release.apk`

Thank you to everyone who tested and supported the beta.
